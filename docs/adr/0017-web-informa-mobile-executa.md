# Web informa, mobile executa

As telas web são somente leitura para sessão de treino e log de refeição: quem executa
é o mobile, que é onde o aluno está com o celular na mão durante o treino. A web serve
para planejar e acompanhar. Sem essa linha, cada tela vira uma negociação sobre em qual
plataforma o aluno registra o que fez, e as duas acabam meio implementadas.

## Consequências

- `student` não vê CTA de criação em lugar nenhum — vê mensagem passiva, porque quem
  cria o plano dele é o specialist.
- `member` usa o fluxo de periodização completo, com a mesma hierarquia do specialist e
  adaptação só de texto. Não existe tela simplificada paralela para manter.
