Small uppercase status pill — use for account status (Ativo/Pendente), plan tier, workout status (Rascunho/Concluído).

```jsx
<Badge tone="success">Ativo</Badge>
<Badge tone="warning" dot={false}>Rascunho</Badge>
```

Tones map to semantic tokens: `success` emerald, `warning` amber, `danger` red, `primary` lime, `secondary` cyber blue, `neutral` zinc.
