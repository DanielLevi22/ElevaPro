Pill-shaped call-to-action button used across the marketing site, dashboard, and mobile app; use for any primary or secondary action.

```jsx
<Button variant="primary" size="md">Começar Agora</Button>
<Button variant="outline">Ver Demonstração</Button>
```

Variants: `primary` (lime fill, black text, glows on hover), `secondary` (translucent white fill), `outline`, `ghost`, `destructive` (delete/remove actions). Sizes `sm`/`md`/`lg`. `isLoading` swaps content for an ellipsis; `fullWidth` stretches to container.
