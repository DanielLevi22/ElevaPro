Base surface container — every panel, tile, and list item in the product is a Card with content composed inside it.

```jsx
<Card><h3>Título</h3><p>Conteúdo</p></Card>
```

Border brightens to lime and a soft shadow appears on hover by default (`hoverable`). Radius defaults to 24px (`--radius-2xl`); pass `radius="var(--radius-panel)"` for the 40px sidebar-panel look.
